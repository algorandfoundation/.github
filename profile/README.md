# Algorand Foundation

This GitHub organization contains the code repositories of the Algorand Foundation.

## [Developer Portal](https://dev.algorand.co)

The developer portal contains the official documentation for the Algorand blockchain and its AlgoKit developer toolkit.

## [Algorand Protocol](https://github.com/algorand)

This separate GitHub organization houses the core Algorand protocol, its SDKs, the indexer, and other tools created by Algorand Technologies.
